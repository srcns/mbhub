## Transparency first

MBHub is **not Open Source** in the OSI-defined sense. It is **Source Available**:
anyone can read, inspect, audit, fork, learn from, and run the code under the
terms of the PolyForm Noncommercial license. What is reserved is the
**commercial use** right — it belongs exclusively to the project copyright
holder. This statement is made deliberately and up front, so expectations are
clear from the first line.

## What you CAN do (free, no permission needed)

- **Personal use** — run your own node, build your own memory, use the CLI and TUI.
- **Education & research** — study the code, write about it, use it in coursework or non-funded academic research.
- **Inspection & audit** — clone, read, and evaluate the source for security or compatibility purposes.
- **Forking** — fork the repository for non-commercial experimentation and contribution back.
- **Contributions** — send improvements via pull requests (see [CONTRIBUTING.md](CONTRIBUTING.md) for the CLA requirement).

## What requires a commercial license

Any use primarily intended for or directed toward **commercial advantage or
monetary compensation**, including:

- Embedding or bundling MBHub (or a derivative of it) into a paid product or appliance.
- Offering MBHub, or a service built on it, as a **paid SaaS / hosted offering**.
- Running MBHub inside a **company-internal production workflow** that supports revenue-generating operations.
- Redistributing derivatives under terms that conflict with the PolyForm Noncommercial license.
- Using MBHub in paid consulting engagements where it constitutes a substantial component of the deliverable.

If you are unsure whether your use case is commercial, ask us —
[licensing@mbhub.dev](mailto:licensing@mbhub.dev). We answer quickly and in plain language.

## How to obtain a commercial license

Contact **[licensing@mbhub.dev](mailto:licensing@mbhub.dev)** with:

1. Your company / organization name
2. Intended use (embed / SaaS / internal / redistribute)
3. Expected scale (seats, instances, or regions)

We offer simple flat licenses for startups and scalable terms for larger deployments.

## Why this model?

Building a sovereign, serverless collective memory network takes sustained,
long-term engineering. The source stays open for everyone to inspect and learn
from; commercial licensing funds that work and keeps development independent.
The model also keeps the project **acquirable as a single, clean entity**
(code + brand + commercial rights) if a strategic partner ever wants to take
it forward — which is only possible when commercial rights are consolidated
from day one.
